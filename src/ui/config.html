API local

Qualquer script, programa ou automação pode falar com o painel por HTTP em http://127.0.0.1:7878. É o mesmo caminho que o MCP e os hooks usam. ?

RotaPara quê
POST /mensagemMostra uma mensagem. Corpo em texto puro ou JSON: texto, cor, efeito (rolar | fixo | piscar), repetir, segundos, em_minutos (vira lembrete). Os campos também podem ir na URL (?cor=verde&efeito=piscar).
POST /texto?nome=XDefine o texto exibido nos blocos var:X. Corpo vazio apaga.
POST /limparDescarta mensagens e lembretes pendentes.
GET /statusCPU, RAM, conexão, próximos compromissos, textos e fila (JSON).
GET /claudeSessões do Claude Code e limites de uso (JSON).
POST /claude-hookRecebe o JSON dos hooks do Claude Code (atualiza as sessões e mostra avisos).
POST /claude-statuslineRecebe o JSON da statusline do Claude Code (limites, modelo, contexto) e responde a linha do terminal.

Exemplos (curl, funciona no Windows, Linux e macOS):

curl -X POST "http://127.0.0.1:7878/mensagem?cor=verde" --data "Backup concluído"
curl -X POST http://127.0.0.1:7878/mensagem -H "Content-Type: application/json" -d "{\"texto\":\"Servidor fora do ar\",\"efeito\":\"piscar\"}"
curl -X POST "http://127.0.0.1:7878/texto?nome=status&cor=ciano" --data "Build #42 rodando"

PowerShell:

Invoke-RestMethod -Method Post "http://127.0.0.1:7878/mensagem?efeito=piscar" -Body "Atenção!"

Python:

import urllib.request urllib.request.urlopen(urllib.request.Request("http://127.0.0.1:7878/mensagem?cor=rosa", data="Treino terminou".encode()))
